# html-lesson

A practice page from my HTML learning. It collects things I build as I work
through [MDN's Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development)
material.

## What's in it

| File | What it is |
|------|------------|
| `index.html` | The lesson page: headings, paragraphs, line breaks, `<em>`/`<strong>`, horizontal rules, HTML entities, and `<head>` metadata (author, description, favicon) |
| `main.css` | Minimal stylesheet: larger base font size and a dark background with light text |
| `html5.png` | Favicon |

## Run it

No build step and no dependencies. Open `index.html` in a browser.

## Status

Beginner practice work. The page grows as I learn new elements.
